# Zepto-Sales-Analysis
The project focuses on analyzing sales, delivery, and inventory operations for a Zepto-style quick commerce business using SQL and Power BI. The objective was to generate business insights related to revenue trends, delivery  performance, inventory monitoring, and return analysis through interactive dashboards and SQL based KPI analysis.

# Problem Statement
Quick-commerce companies need to efficiently manage sales performance, delivery operations, and inventory availability to improve customer satisfaction and operational efficiency. This project analyzes operational data to identify trends, monitor KPIs, and support data-driven business decisions.

# Dataset Description
The dataset contains simulated quick-commerce transactional data including:
Sales information
Product categories
Inventory details
Delivery performance
Product returns

# SQL Analysis Performed
Imported and structured transactional sales dataset in MySQL
Used SQL queries for KPI analysis and operational insights
Performed data aggregation using SUM(), AVG(), COUNT(), and GROUP BY
Analyzed revenue trends, delivery performance, inventory levels, and return rates
Identified top-selling products and high-performing categories
Calculated business KPIs such as:
o Total Revenue
o Total Orders
o Late Delivery Percentage
o Average Delivery Time
o Return Percentage
o Low Stock Products

# PowerBI Dashboards
1. Sales Dashboard
2. Delivery Dashboard
3. Inventory Dashboard

# Conclusion
This project demonstrates the use of SQL and Power BI to analyze and visualize operational data for a quick-commerce business. The dashboards provide insights into sales performance, delivery efficiency, and inventory management while strengthening practical skills in SQL querying, dashboard development, and business analytics.
